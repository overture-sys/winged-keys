WINGED KEYS

Setup

First-time setup: turn on the Hermes API server
1. Click Make a key. 2. Copy the two lines into your Hermes .env file (Windows: %LOCALAPPDATA%\hermes\.env). 3. Restart the Hermes gateway. 4. Click Find Hermes and confirm the address, then Test connection.
Making a key also puts it in the API key box here, so the plugin and Hermes match. The key is shown in plain text above: don't do this while streaming or sharing your screen.
⚠ Caution: this reads a secret file.
The plugin will open your Hermes .env file on this computer and copy only the API_SERVER_KEY line into this plugin's settings. That key gives full control of your agent, including running commands on this PC. Stream Dock / Stream Deck may store it unencrypted. Only continue on your own computer.
It reads the standard location (Windows: %LOCALAPPDATA%\hermes\.env) unless you set another one under "Hermes .env location" below.

Hermes connection (all keys)

Treat the key like a password. It gives the agent full tool access. It may be stored unencrypted by Stream Dock.
Your API key is never sent to the dashboard.

This Usage key

"All chats" numbers come from the dashboard's analytics and include Discord and Telegram. Each agent keeps its own records; "All agents" adds them up. Cache hit % = cache reads / (input + cache reads).

This Open key

This New chat key

Starts a fresh conversation for the current agent: Ask keys set to "continue the conversation" start over.

This Agent key

Press to switch between your Hermes agents. Ask, Stop, Status and New chat follow the chosen agent.

Hermes requires each named agent (not "default") to have its own API_SERVER_KEY in profiles\<agent>\.env. Add one per agent, restart Hermes, then use Read key from Hermes above.

This Ask key

Whatever you have copied is sent to the agent when you press the key. Don't use this with passwords or private text on the clipboard.
Follow-up presses keep Hermes's memory of earlier answers. Sends go to the agent chosen on the Agent key.
